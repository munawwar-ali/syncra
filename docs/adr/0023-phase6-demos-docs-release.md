# ADR 0023: Phase 6 choices (demos, docs, release)

Status: accepted. Decided without asking, per Doc 00 section 8.

1. **Demo seed lives in the server (DEMO_MODE only).** Sites and templates are written through the document service with fixed Yjs client ids and op ids, so a second node or a restart produces the same updates and the dedup ignores them. A seed built from several documents with the same client id must continue one clock (a bug found while building it).
2. **Inspection roles are enforced in two places.** The token rules limit what the server accepts. The UI also hides or disables what a role cannot do (supervisors cannot submit or edit the checklist); this is a convenience, not security.
3. **SDK fix: unsent edits after a restart.** The engine only sends operations for open documents, so a reload on another screen left edits stuck. `adoptUnsent` re-opens documents that have outbox entries. They stay open until `destroy()`.
4. **Collection titles encode site and template** (`siteId|template|date`) so history lists need no extra document reads.
5. **Docs: VitePress with the Mermaid plugin**, base path `/syncra/` (override with `DOCS_BASE`). Internal specs, ADRs and the traceability matrix are excluded from the site.
6. **Releases:** images to GHCR on `v*` tags; npm packages are a dry run unless a manual run sets `publish=true`. Release notes use GitHub's generated notes; Changesets is installed but not wired.
7. **Terraform AWS reference is skipped** (optional in the plan). The deployment guide covers a single host.
8. **Accepted advisory:** zod 3 (GHSA-mrhx-c7xc-m3w5) until a zod 4 migration; mitigated by body and message size limits. Recorded in docs/security.md and in the pnpm audit config.
9. **Screenshots are generated by Playwright** (`SCREENSHOTS=1`) rather than recorded; the demo video and GIF are not produced, only a script (docs/demo-video-script.md).

## Known gaps

Docker stack, quickstart check, release and deploy workflows have never run. No Lighthouse run. Packages not published. No timed quickstart walkthrough with a person.
