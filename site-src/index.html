Everything between your app and your database

Local-first apps need more than a CRDT. Syncra ships the parts around it.

Offline-first

Edits are applied locally and queued. Conflicts merge automatically with Yjs, so there is no custom merge code to write.

Self-host anywhere

Run the whole stack with Docker Compose on your own infrastructure. Your data stays in your Postgres.

Dashboard included

API keys, usage, a document inspector, webhooks and an audit log, without building an admin tool first.

Up and running in minutes

Start the stack locally, then point the SDK at it.

# run the server and its dependencies
docker compose -f infra/compose/docker-compose.yml up

# add the SDK to your app
pnpm add @syncra/client @syncra/react
